OpenClaw
迁移指南

从 Legacy OpenClaw 平滑过渡到 Hermes Agent v0.9。本指南涵盖了数据完整性校验、系统参数映射及高可用集群的无缝切换流程。

01

备份数据 (Backup Data)

确保所有当前的配置状态与索引数据已进行离线快照，以防迁移中断导致回滚失败。

02

执行迁移 (Execute Migration)

运行二进制迁移工具，Hermes 将自动识别 OpenClaw 数据结构并将其转换为 mTLS 1.3 容器协议。

03

验证一致性 (Verify Consistency)

通过内置的 Checksum 工具验证每一个节点的连通性与数据完整性，确保新系统零误差运行。

hermes-sh — 80×24
➜ ~ hermes claw migrate --target=v0.9

Common Issues

迁移过程中发生 Network Timeout 怎么办？

expand_more
确保您的防火墙已开放 8443 与 9090 端口。若仍超时，请尝试使用 `--force-local` 参数强制在本地节点执行预处理任务。

Hermes v0.9 是否完全向下兼容？

expand_more
Hermes 在 API 层级保持 99% 的兼容性。仅针对过时的静态密钥配置（Static Key Auth）进行了弃用，请迁移至动态 JWT 认证体系。
