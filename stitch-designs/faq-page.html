安装与启动

如何在本地环境快速部署 Hermes Agent？

keyboard_arrow_up

建议使用 Docker 进行快速部署，以避免环境依赖冲突。执行以下命令即可启动：

Terminal
1 git clone https://github.com/hermes/agent.git
2 cd hermes-agent && docker-compose up -d
3 # 等待服务就绪，访问 localhost:3000

模型与 API

key

如何配置 OpenAI API Key？

在项目根目录的 .env 文件中，将 OPENAI_API_KEY 替换为您自己的密钥即可。支持所有符合 OpenAI 格式的中转服务。

支持哪些开源模型？

Hermes 原生支持 Llama 3, Qwen 2, 以及 Mistral。您可以通过 Ollama 或 LocalAI 进行本地化集成。
