# Structured Content — OpenClaw vs Hermes 中文版信息图

## Title
OpenClaw vs Hermes 怎么选？

## Learning Objective
帮助读者在 30 秒内理解两个 AI Agent 框架的核心差异，做出适合自己的选择。

## Sections

### Section 1: 核心权衡（顶部横幅对比）
- **OpenClaw**: 确定性，而非默认值 | 像 Linux — "boring in the best way"
- **Hermes**: 观点，而非原语 | 像 Rails — "更多内置电池，更少决策"

### Section 2: 设计理念（双栏）
- **OpenClaw**: 原子能力 + 显式产物 → ClawHub 驱动
- **Hermes**: 开箱即用 + 自编写循环 → 安装即带 123 个技能

### Section 3: 技能发现（双栏）
- **OpenClaw**: 有界发现（5 个来源），代码 Agent 不会加载邮件技能
- **Hermes**: 技能膨胀风险（创建多于整合）

### Section 4: 选择建议（双栏 + 检查清单）
- **选 OpenClaw**: 100% 控制权 / 生产交付 / 团队使用 / 可读性优先
- **选 Hermes**: 快速上手 / 第一天产出 / 低维护 / 快乐路径内置

### Section 5: 产品定位（底部）
- **OpenClaw**: 设定了标准（mindshare + stars）
- **Hermes**: 定义了新赛道（重新定义品类）

### Section 6: CTA
- "选哪个都行 · 都没问题 · 去创造点有用的东西吧"

## Data Points
- OpenClaw GitHub Stars: 大量（mindshare 基准）
- Hermes: 安装即带 123 个技能
- 对比维度: 6 个
