# OpenClaw vs Hermes 对比信息图

## 核心权衡（Core Tradeoff）

### OpenClaw
- **Guarantees, not defaults** — 类似于 Linux
- "does exactly what you told it, boring in the best way"

### Hermes
- **Opinions, not primitives** — 类似于 Rails
- "more batteries, fewer decisions"

## 设计理念（Philosophy）

### OpenClaw
- **primitives** — 原子能力，自由组合
- **Explicit artifacts** — 显式产物
- 新技能走 ClawHub 社区，核心极少改动

### Hermes
- **batteries included** — 开箱即用
- **Self-authoring loop** — 自编写循环
- 调用 N 次后自动沉淀为 skill，后台 review

## 技能发现与范围（Skill Discovery & Scope）

### OpenClaw
- **Bounded discovery** — 有界发现
- 5 个排名来源，代码 agent 不加载邮件技能

### Hermes
- **Skill explosion risk** — 技能膨胀风险
- 创建的技能多于整合的

## 选择建议（Which One）

### 选 OpenClaw 如果你：
- 想要 **100% 控制权**
- 在 **生产环境** 或 **团队** 中交付
- **可读性** 比 **速度** 更重要

### 选 Hermes 如果你：
- 想要 **快速上手**（Getting started quickly）
- 第一天就能产出（day one productivity）
- **低维护**，**快乐路径** 已内置（happy path built in）

## 产品定位（Positioning）

- **OpenClaw** "set the standard" — 设定了标准（mindshare + GitHub stars）
- **Hermes** "made a new game" — 定义了新赛道（redefined the category entirely）
