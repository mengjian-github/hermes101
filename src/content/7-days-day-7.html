定时任务（Cron）

Hermes 内置 cron 调度器，可用自然语言创建定时任务：

terminal
$ hermes cron create --schedule "0 9 * * *" --prompt "总结今天的新闻并发送到 Telegram" ✓ Job created: daily-news

常用 cron 命令：

terminal
$ hermes cron list # 查看所有任务 $ hermes cron pause 1 # 暂停任务 $ hermes cron resume 1 # 恢复任务 $ hermes cron run 1 # 立即触发一次 $ hermes cron remove 1 # 删除任务

任务可以附加技能（--skill），执行时自动加载。

2

Webhook 触发

通过 webhook 让外部事件触发 Hermes（如 GitHub PR、CI 构建完成）：

terminal
$ hermes webhook subscribe github-pr --prompt "Review this PR: {pull_request.title}" --events pull_request --deliver telegram Webhook URL: https://your-server/webhook/github-pr Secret: whsec_xxx

订阅持久化到 ~/.hermes/webhook_subscriptions.json，gateway 热重载无需重启。

3

诊断问题

遇到问题时的诊断工具链：

terminal
$ hermes status # 查看模型、平台、工具状态 $ hermes doctor # 自动诊断配置和依赖 $ hermes dump # 导出完整配置摘要（用于求助） $ hermes debug share # 上传调试报告获取分享链接

hermes dump 输出示例：

terminal
--- hermes dump --- version: 0.10.0 model: anthropic/claude-sonnet-4 provider: openrouter gateway: running (systemd) platforms: telegram, discord cron_jobs: 3 active skills: 42 --- end dump ---
4

查看日志

terminal
$ hermes logs -f # 实时跟踪 agent 日志 $ hermes logs gateway -n 100 # 查看 gateway 最近 100 行 $ hermes logs --level WARNING --since 1h # 最近 1 小时的警告和错误 $ hermes logs --session abc123 # 过滤特定会话
5

从 OpenClaw 迁移

如果你有 OpenClaw 历史配置，Hermes 提供自动迁移：

terminal
$ hermes claw migrate --dry-run # 预览将要迁移的内容 $ hermes claw migrate # 完整迁移（包含 API key） $ hermes claw migrate --preset user-data # 只迁移用户数据（不含 secrets）

迁移覆盖 30+ 类别：SOUL.md、MEMORY.md、技能、模型配置、平台 token、MCP 服务器等。

如果 OpenClaw 已卸载，手动复制：cp ~/.openclaw/config.yaml ~/.hermes/ 后再运行迁移。

6

进阶：MCP 集成

通过 MCP（Model Context Protocol）连接外部工具和服务：

terminal
$ hermes mcp add playwright --command npx --args @playwright/mcp@latest $ hermes mcp list $ hermes mcp test playwright

MCP 让 Hermes 能安全地调用外部服务器提供的工具，如数据库、浏览器自动化、文件系统等。

✅ 你将看到
$ hermes cron create --schedule "0 9 * * *" --prompt "总结今天的新闻" ✓ Job created: daily-news $ hermes status Model: anthropic/claude-sonnet-4 ✓ Gateway: running Platforms: telegram ✓, discord ✓ Skills: 5 installed $ hermes claw migrate --dry-run Would migrate: SOUL.md, 12 skills, config.yaml, telegram token...
⚠️ Cron 任务没有触发

检查 hermes cron list 中任务状态；确认 gateway 正在运行；cron 调度器需要 gateway 或独立 cron 进程。

⚠️ hermes debug share 上传失败

加 --local 参数在本地输出报告：hermes debug share --local

⚠️ migrate 报错 'claw 不存在'

确认 ~/.openclaw 目录存在；如已卸载，手动复制 config.yaml 后重试。
