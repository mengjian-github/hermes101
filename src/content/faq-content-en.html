Setup and Installation

No. hermes101.dev is an independent beginner guide. The official Hermes Agent docs are at hermes-agent.nousresearch.com/docs. Every setup page links back to the official source and shows when it was last checked.

For Linux, macOS, WSL2, or Termux: curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash. For native Windows PowerShell: iex (irm https://hermes-agent.nousresearch.com/install.ps1). Always verify against the official docs before running install commands.

Use hermes setup --portal if you want the easiest guided path through Nous Portal. Use hermes model if you already know which provider, model, API key, or custom endpoint you want to use.

A plain CLI chat should work first. Start hermes, ask a normal question, and confirm it returns a useful answer. Only then set up messaging with hermes gateway setup.
