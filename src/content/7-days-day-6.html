1

理解记忆系统

Hermes 有两层记忆：

  • 内置记忆（始终活跃）：MEMORY.md（环境/项目信息）、USER.md（用户画像），跨会话持久
  • 外部记忆 provider（可选）：Honcho、mem0 等，提供更强大的跨会话检索和推理

对话过长时，Hermes 会自动压缩上下文，将关键信息写入记忆文件。

2

手动压缩上下文

当对话变长或需要刷新记忆时：

terminal
You: /compress Compressing context... Summary saved to memory. You: /compress 项目进度 Compressing with focus: "项目进度"

可带可选参数聚焦特定主题，压缩后只保留相关信息。

3

查看记忆文件

Hermes 的记忆存储在文本文件中，可直接查看和编辑：

terminal
$ cat ~/.hermes/MEMORY.md # Memory - 用户偏好：使用中文交流 - 项目：hermes101 站点开发中 $ cat ~/.hermes/USER.md # User Profile - 编程语言：Python, TypeScript

这些文件会在每次对话后自动更新。你也可以手动编辑来修正或补充信息。

4

会话管理

Hermes 自动保存所有会话。在 CLI 中用 /history 查看当前会话历史，用 /title 给会话命名以便识别。

terminal
You: /history [1] You: 你好 [2] Hermes: 你好！有什么可以帮你的？ You: /title Day 1 安装配置 Session title set: Day 1 安装配置

终端命令管理会话：

terminal
$ hermes sessions list # 列出所有会话 $ hermes sessions browse # 交互式选择并恢复 $ hermes sessions export backup.jsonl # 导出
5

创建备份

terminal
$ hermes backup ✓ Backup saved: ~/hermes-backup-2026-04-20-143000.zip $ hermes backup --quick --label "pre-upgrade" ✓ Quick snapshot: pre-upgrade

--quick 只备份关键状态文件（config.yaml、state.db、.env），速度更快。

6

恢复备份

terminal
$ hermes import ~/hermes-backup-2026-04-20-143000.zip ✓ Restored 42 skills, config, and memories

备份使用 SQLite 的 backup() API，即使 Hermes 正在运行也能安全备份（WAL 模式安全）。

✅ 你将看到
You: /compress Compressing context... Summary saved to memory. $ hermes backup ✓ Backup saved: ~/hermes-backup-2026-04-20-143000.zip $ hermes sessions list Recent sessions: 1. Day 1 安装配置 (2h ago) 2. Day 2 模型配置 (1d ago)
⚠️ hermes backup 报错权限不足

检查 ~/.hermes 目录是否有可读权限；backup 会自动跳过过大的源码目录。

⚠️ hermes import 提示不是有效的备份

确认 zip 内包含 config.yaml 或 .env；手动压缩的目录需确保结构正确。

⚠️ MEMORY.md 为空

内置记忆需要对话积累；多聊几轮后 Hermes 会自动提取关键信息写入 ~/.hermes/MEMORY.md。
